# specdive

MCP tools that write feature specs into `.specdive/`. `specdive view` serves them locally.

```bash
specdive init --target cursor    # or opencode
specdive view                    # http://127.0.0.1:4747
specdive mcp
```

Build from source: [CONTRIBUTING.md](CONTRIBUTING.md).

```
specdive init [--target <cursor|opencode>]
specdive update
specdive install --target <cursor|opencode>
specdive view [--port <4747>] [--host <127.0.0.1>]
specdive mcp
```
